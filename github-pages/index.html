Mermaid CYD Flasher

Flash the complete Mermaid UI R2 firmware directly from GitHub Pages. No Arduino IDE, PlatformIO, or manual BIN selection.

Flash
4 MB
Display

XPT2046 resistive
One-click installer
This browser cannot flash over Web Serial. Use a supported desktop browser, or use the native Termux NR path on Android. Web flashing requires this HTTPS GitHub Pages site.

The installer detects an ESP32 and writes the merged 4 MB factory image at 0x0. The image already contains the bootloader, partition table, boot_app0, and Mermaid application.

After flashing

The CYD should reboot into Mermaid UI R2. Complete the four-point resistive-touch calibration. Serial identity should report:
MERMAID_HELLO role=CYD hw=ESP32-WROOM-32E-N4 proto=MVP1

Firmware is built by GitHub Actions from feat/cyd-android-codex-cli-automation and packaged as a merged ESP32 image before deployment.
